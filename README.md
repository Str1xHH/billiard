# Бильярд — дневник тренировок

Офлайн-приложение (PWA) для учёта тренировок по бильярду: https://str1xhh.github.io/billiard/

- Работает без интернета, ставится на экран «Домой» iPhone.
- Данные хранятся на телефоне и автоматически копируются в приватный репозиторий `billiard-data`.
- Копию можно сохранить и файлом (раздел «Копии»).
- Аккаунт: вход через GitHub, тренировки хранятся в аккаунте; вкладка «Друзья» — заявки в друзья и таблица лидеров по точности ударов.

## Сервер аккаунтов (`api/`)

Функция Yandex Cloud Functions (Node.js 22), данные — JSON-файлы в приватном бакете Object Storage.
Выкладывается сама при изменениях в `api/` (`.github/workflows/api.yml`): GitHub получает временный ключ
Yandex Cloud через федерацию сервисных аккаунтов, хранимых ключей нет. Секрет репозитория — только `GH_CLIENT_SECRET`
(OAuth-приложение «Бильярд — дневник тренировок»). Проверки без облака: `node api/test.js`.

При изменении файлов приложения повышай номер версии `CACHE` в `sw.js`, чтобы телефон подтянул обновление.
