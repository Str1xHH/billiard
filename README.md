# Бильярд — дневник тренировок

Офлайн-приложение (PWA) для учёта тренировок по бильярду: https://str1xhh.github.io/billiard/

- Работает без интернета, ставится на экран «Домой» iPhone.
- Данные хранятся на телефоне и автоматически копируются в приватный репозиторий `billiard-data`.
- Копию можно сохранить и файлом (раздел «Копии»).

При изменении файлов приложения повышай номер версии `CACHE` в `sw.js`, чтобы телефон подтянул обновление.
